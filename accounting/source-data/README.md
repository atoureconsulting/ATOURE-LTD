# Source data

Drop raw records here (or tell me the figures directly in chat and I'll
log them). Useful formats: bank statement CSV/PDF exports, invoice PDFs,
receipt photos, a spreadsheet of transactions — anything is fine, messy or
tidy.

Suggested subfolders (create as needed):
- `bank-statements/`
- `sales-invoices/`
- `expense-receipts/`
- `misc/`

Every time data lands here, it gets reflected in:
- `../periods/2023-09-11_2024-09-10/profit-and-loss.md`
- `../periods/2024-09-11_2024-09-30/profit-and-loss.md`
- `../periods/balance-sheet.md`

...and the reasoning for how it was categorised gets logged in
`/notes.md`.
